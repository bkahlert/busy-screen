Busy Screen apt repository

Debian packages that put Busy Screen, the desk status display, on a Pi Hero device: busy-screen-server (the Node-RED backend that takes status updates) and busy-screen-display (the web display in a kiosk). The packages, their source, and the device file that installs them on first boot live at github.com/bkahlert/busy-screen.

Add the repository

The flat repository at /busy-screen/apt is signed with the key whose fingerprint is 3A5D E4B9 1CA8 7199 C42D FC90 9C28 3531 C9B0 65B6. Device files embed it; on an existing system:

curl -fsSL https://bkahlert.github.io/busy-screen/apt/busy-screen-apt.asc | sudo tee /etc/apt/keyrings/busy-screen.asc >/dev/null
sudo tee /etc/apt/sources.list.d/busy-screen.sources >/dev/null <<'SOURCES'
Types: deb
URIs: https://bkahlert.github.io/busy-screen/apt
Suites: ./
Signed-By: /etc/apt/keyrings/busy-screen.asc
SOURCES
sudo apt update && sudo apt install busy-screen-server busy-screen-display
